ExamForge is an **AI-powered exam generator**:

- ✍️ Answer questions and get instant scoring
- 📚 Save exams to your personal question bank

## ⚡ Getting Started (5 Minutes)

### **1. Open the App**
Visit: `https://your-app-url` (or add to home screen)

### **2. Understand the Screens**

| Screen | Purpose |
|--------|---------|
| **Onboard** | Welcome & feature overview |
| **Main** | Generate new exams from PDFs |
| **Exam** | Take exam, answer questions |
| **Bank** | View all saved exams |
| **Paywall** | Buy credits after 2 free exams |

### **3. Generate Your First Exam**

```
1. Click "Main" tab
2. Select a subject (or long-press to rename)
3. Tap PDF upload area
4. Choose a text-based PDF from your device
5. Click "Generate Exam"
6. Wait 10-30 seconds
7. Your exam is ready!
```

### **4. Take Your Exam**

```
1. Read question carefully
2. Select your answer
3. Tap "✓ Check" to see if correct
4. See score after last question
5. Click "Retake" to shuffle questions
```

## 📊 Feature Breakdown

### **Main Tab - Generate Exams**

**Select Subject:**
- 6 default subjects (Engineering, Topik, English, etc.)
- **Long-press** any subject to rename it
- Use names like "ENG101", "Bio 101", "Chemistry"

**Upload PDF:**
- Tap the upload area
- Select any text-based PDF
- Files should be:
  - ✅ Text-based (searchable)
  - ✅ Under 20MB
  - ❌ NOT scanned images
  - ❌ NOT password protected

**Configure Exam:**

| Setting | Options | Impact |
|---------|---------|--------|
| **Questions** | 5, 8, 10, 15, 20 | Longer = more time |
| **Difficulty** | Easy, Medium, Hard, Mixed | Changes question complexity |
| **Type** | MC, T/F, SA, Mixed | Question format |
| **Language** | 9 languages | Question language |
| **Explanations** | Yes/No | Show answers after |

**Settings explained:**
- **Easy** = Basic concepts (15 min)
- **Medium** = Standard curriculum (25 min)
- **Hard** = Advanced topics (35 min)
- **Mixed** = Random difficulty

**Question Types:**
- **MC** = Multiple choice (4 options)
- **T/F** = True/False (2 options)
- **SA** = Short answer (type response)
- **Mixed** = 50% MC, 25% T/F, 25% SA

## ❓ FAQ

**Q: Is my data private?**  
A: Yes! All data stored on your device. We don't access your PDFs or exams.

**Q: Can I use offline?**  
A: Mostly yes! PDF upload and exam generation need internet. But taking exams works offline.

**Q: How accurate are AI questions?**  
A: Very! Uses Claude AI (same as ChatGPT level). Quality depends on PDF quality.

**Q: What file formats work?**  
A: PDF only. Must be text-based (searchable), not scanned images.

**Q: Can I get refunds?**  
A: Credits are non-refundable but never expire, so you can use them anytime.

**Q: How long does generation take?**  
A: Usually 10-30 seconds. Depends on PDF size and complexity.

**Q: Can I share codes with friends?**  
A: No, access codes are 1-time use per device. But you can buy separate codes.

**Q: Does exam generation work offline?**  
A: No, needs internet. But once generated, exams work offline.

**Q: How many subjects can I have?**  
A: Unlimited! Create as many as you need.

**Q: Can I edit generated questions?**  
A: Not yet, but we're working on it for v3.0

## 🎓 Learning Tips

### **Most Effective Study Method:**

```
1. Generate 10-question exam (Medium difficulty)
2. Take without looking at answers
3. Check answers and read explanations
4. Study explanations for wrong answers
5. Wait 24 hours
6. Retake same exam
7. Aim for 90%+ score
8. Move to next topic
```

### **For Standardized Tests (TOEFL, SAT, etc.):**

```
1. Gather sample materials for each section
2. Use "Mixed" question types
3. Set to Hard difficulty
4. Generate 15-20 questions
5. Take timed (time yourself)
6. Review carefully
7. Repeat until scoring 85%+
```

### **For Class Preparation:**

```
1. After each lecture, upload lecture notes
2. Generate Medium difficulty exam
3. Take to check understanding
4. Save to Question Bank
5. Review before class test
6. Retake for last-minute review
```
