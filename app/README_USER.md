# 📱 ExamForge - User Guide

Welcome to **ExamForge**, your AI-powered exam generator! This guide will help you get started.

## 🚀 Quick Start (2 Minutes)

### **Step 1: Open the App**
- Go to your ExamForge URL
- You'll see the onboarding screen with 3 simple steps
- Tap **"Get Started →"** button

### **Step 2: Choose a Subject**
Select one of these subjects (or rename to your class name):
- 📚 **Engineering**
- 📚 **Topik**
- 📚 **English**
- 📚 **PLC**
- 📚 **Law**
- 📚 **Korean Language**

### **Step 3: Upload Your PDF**
- Tap the **PDF upload area**
- Select a text-based PDF (lecture notes, textbook chapters, etc.)
- ✅ File must be text-based (not scanned/image-only)

### **Step 4: Generate Exam**
- Adjust settings if you want (number of questions, difficulty, type)
- Tap **"Generate Exam"** button
- Wait 10-30 seconds for AI to create questions

### **Step 5: Study & Score**
- Read each question
- Answer in Study Mode
- Tap **"✓ Check"** to see your score
- Review correct answers with explanations
- **Retake** to shuffle questions and try again

## 🎯 Exam Settings Explained

### **Number of Questions**
- 5, 8, 10, 15, or 20 questions
- More questions = longer exam

### **Difficulty**
- **Easy** — Basic concepts
- **Medium** — Standard curriculum
- **Hard** — Advanced/challenging
- **Mixed** — Random difficulty

### **Question Type**
- **MC Only** — Multiple choice only
- **T/F Only** — True/False only
- **SA Only** — Short answer only
- **Mixed** — 50% MC, 25% T/F, 25% SA

### **Language**
- Generate exams in 9 languages:
  - English, 한국어 (Korean), 中文 (Chinese)
  - Español (Spanish), Français (French)
  - Deutsch (German), العربية (Arabic)
  - සිංහල (Sinhala), 日本語 (Japanese)

### **Explanations**
- **Yes** — Show answer explanations after checking
- **No** — Just show correct answer

## 📖 Study Modes

### **Study Mode ✏️**
- Answer all questions without checking
- Tap **"✓ Check"** to reveal answers
- Shows your score with percentage
- See explanations for each answer

### **Review Mode 📖**
- See all questions with answers already shown
- Perfect for learning after checking
- Use buttons: **"Show Answer"** or **"Hide Answer"**

### **Retake 🔀**
- Questions are **shuffled randomly**
- Try again with same exam
- Better for memorization
- Check score again
